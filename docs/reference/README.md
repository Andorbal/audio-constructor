node. Edit the node's source, not these files.

"Try this" tip, and every socket with its type, default, and range. The same
text is in the editor's Help tab (`F1` on a node). For how the nodes fit
together, read the [user guide](../guide/README.md).

## Input / Output

Sound, MIDI, and controls coming into and going out of the patch: audio devices, MIDI ports, gamepads, the computer keyboard, OSC, and files. All on one page: [Input / Output](io.md).

| Node | What it does |
| --- | --- |
| [Audio In](io.md#audio-in) | Brings a device input channel, or a pair of them, into the patch. *Live source.* |
| [Audio Out](io.md#audio-out) | Sends audio to the device outputs. |
| [File Out](io.md#file-out) | Renders its input to a file of its own when the project is rendered offline. |
| [Gamepad](io.md#gamepad) | Brings a game controller into the patch: every button as a gate and a press trigger, the sticks and analog triggers as numbers. *Live source.* |
| [Keyboard In](io.md#keyboard-in) | Brings the computer keyboard into the patch: chosen keys as gates and press triggers, and a row of letter keys played like a piano. *Live source.* |

| [MIDI Out](io.md#midi-out) | Sends MIDI to the connected devices. |

## Generators

Sources of signal over time: oscillators, noise, audio files, samplers, drawn curves, and the song position. All on one page: [Generators](generators.md).

| Node | What it does |
| --- | --- |
| [Clip](generators.md#clip) | Plays an audio file, with looping, reverse, and variable speed. |

| [Oscillator](generators.md#oscillator) | A periodic waveform (sine, triangle, saw, square, or pulse) at `freq` + `fm` Hz, as a sample-rate `Float` that wires into audio or into any parameter. |
| [Sampler](generators.md#sampler) | Plays a recorded sound at any pitch, with start and end points, a sustain loop, and the generator contract: the building block for drum machines and sampled instruments. |
| [Transport](generators.md#transport) | Song time as signals: seconds, beats, bars, tempo, and play state. |
| [Wavetable](generators.md#wavetable) | An oscillator that plays single-cycle waveforms from a table and morphs between them with `position`, as a sample-rate `Float`. |

## Level & Dynamics

Volume, panning, and mixing, and the parts that compressors, limiters, and gates are built from. All on one page: [Level & Dynamics](level.md).

| Node | What it does |
| --- | --- |
| [Crossfade](level.md#crossfade) | Blends two signals: `mix` 0 is all `a`, 1 is all `b`, and values in between mix them. |
| [Envelope Follower](level.md#envelope-follower) | Measures how loud a signal is, moment to moment: `level` (linear, 0 to 1 for full scale) and `level_db` (decibels, never below −120), both at sample rate. |
| [Gain](level.md#gain) | Scales a signal by a gain in decibels. Works on any number of channels. |
| [Gain Computer](level.md#gain-computer) | Turns a level into a gain change: the decision-making half of a compressor, limiter, expander, or gate. |
| [Lookahead](level.md#lookahead) | Lets a level detector see the signal before it is heard: `out` is the input delayed by `time`, and `early` is the input as it comes in, `time` ahead of `out`. |
| [Mix](level.md#mix) | Sums several audio signals into one, each with its own gain in decibels. |
| [Normalize](level.md#normalize) | Turns a whole signal up or down so its peak, or its loudness, lands on `target`. *Needs its whole input: baked, or off while live.* |
| [Pan](level.md#pan) | Places a mono signal in the stereo field, or shifts the balance of a stereo one. The output is always stereo. |
| [Shaper](level.md#shaper) | Waveshaping: bends the signal through a curve for saturation, clipping, folding, or any transfer function you draw. |

<a id="filters"></a>
## Filters

Filters for shaping tone, for synth sounds, and for building reverbs and resonators. All on one page: [Filters](filters.md).

| Node | What it does |
| --- | --- |
| [Allpass](filters.md#allpass) | A Schroeder allpass filter: smears a signal into a train of echoes without changing its level at any frequency. |
| [Biquad](filters.md#biquad) | A two-pole filter: lowpass, highpass, bandpass, notch, peak, low shelf, or high shelf. Works on any number of channels, each with its own state. |
| [Comb](filters.md#comb) | A comb filter: a copy of the input delayed by `delay`, fed back (a resonator ringing at 1 / `delay`) or added once (evenly spaced notches). |
| [DC Block](filters.md#dc-block) | Removes DC offset: a gentle one-pole highpass that pulls a signal back to center without touching anything you can hear. |
| [Formant](filters.md#formant) | A vowel filter: three resonances placed where a voice puts them for "a", "e", "i", "o", and "u", so a bright sound fed through it seems to speak. |
| [Ladder](filters.md#ladder) | A four-pole transistor-ladder filter with drive: warm, squelchy, and able to self-oscillate. |
| [SVF](filters.md#svf) | A resonant state-variable filter with lowpass, bandpass, highpass, and notch outputs at once: the synth filter. |

<a id="time"></a>
## Time

Effects that work with time: delays, reversing, freezing, pitch shifting, and diffusion. All on one page: [Time](time.md).

| Node | What it does |
| --- | --- |
| [Convolution](time.md#convolution) | Plays its input through a recorded *impulse response*: the sound of a room, a speaker cabinet, a spring, or any filter, captured as the echo of a single click. Every sample of the input sets off a copy of the response, scaled by that sample, and the copies add up (convolution), so the input sounds as if it were played in that room or through that cabinet. |
| [Delay](time.md#delay) | Echoes: the input comes back after `time`, repeating with `feedback`, blended with the dry signal by `mix` (0 dry, 1 wet). |
| [Diffuser](time.md#diffuser) | Smears a signal into a dense wash: eight modulated allpass filters in series per channel, the building block of a reverb. |
| [Freeze](time.md#freeze) | Holds a short loop of the input while `hold` is on: catch a moment and let it ring forever. |
| [Pitch Shift](time.md#pitch-shift) | Shifts pitch up or down without changing speed, with the formants (the vowel color of a voice) kept in place or moved on their own. |
| [Reverse](time.md#reverse) | Plays its input backwards. *Needs its whole input: baked, or off while live.* |
| [Time Stretch](time.md#time-stretch) | Plays its input slower or faster without changing its pitch. *Needs its whole input: baked, or off while live.* |

<a id="spectral"></a>
## Spectral

Work in frequencies instead of samples: transforms to and from spectra, band splitting, spectral gating and shifting, and pitch detection. All on one page: [Spectral](spectral.md).

| Node | What it does |
| --- | --- |
| [Band Split](spectral.md#band-split) | Splits a signal into frequency bands, one output per band, that add back up to the original. |
| [FFT](spectral.md#fft) | Turns audio into a stream of spectra: a short-time Fourier transform of `in`, one frame every hop. |
| [IFFT](spectral.md#ifft) | Turns a stream of spectra back into audio by overlap-adding inverse transforms. |
| [Pitch Detect](spectral.md#pitch-detect) | Follows the pitch of a monophonic sound: frequency, nearest note, how sure it is, and a trigger when a new note starts. |
| [Spectral Freeze](spectral.md#spectral-freeze) | Holds one moment of a sound and keeps it ringing: while `hold` is on, the spectrum stops changing and plays the frame it caught, for as long as you like. |
| [Spectral Gate](spectral.md#spectral-gate) | Silences the bins of a spectrum that fall below a threshold, leaving the louder ones: a noise gate per frequency. |
| [Spectral Shift](spectral.md#spectral-shift) | Moves every partial of a spectrum to a new frequency: `frequency × scale + shift`. |

| Node | What it does |

| [Logic](math.md#logic) | Combines two gates, `a` and `b`, with a logic operation. |

| [Merge](math.md#merge) | Combines several MIDI or trigger streams into one, so two sources can play one instrument at once. |

| [Select](math.md#select) | Passes on one of several inputs, picked by `index`. |
| [Smooth](math.md#smooth) | Smooths a changing value: a slew limiter or a one-pole smoother, with separate times for rising and falling. |
| [Switch](math.md#switch) | Passes on `a` while `select` is false and `b` while it is true. |
| [Text to Number](math.md#text-to-number) | Reads a number out of text: with the pattern `/fader/{}`, the text `/fader/3` gives 3. |
| [Unary](math.md#unary) | Applies a one-input function to `in`: trigonometry, exponentials, rounding, and the like. |

## Modulation

Envelopes, LFOs, step sequencers, and random movement, for moving other nodes' inputs over time. All on one page: [Modulation](modulation.md).

| Node | What it does |
| --- | --- |
| [ADSR](modulation.md#adsr) | An attack-decay-sustain-release envelope: when the gate opens it rises to 1, falls to `sustain`, and holds; when the gate closes it falls to 0. The output is a sample-rate `Float` from 0 to 1. |
| [Chaos](modulation.md#chaos) | Modulation from a strange attractor: three signals, `x`, `y`, and `z`, that swirl in a pattern that never quite repeats, each between about −1 and 1. |
| [Envelope](modulation.md#envelope) | A multi-stage envelope drawn as breakpoints: it plays a curve of levels over time each time it starts, with an optional sustain point and loop. |
| [LFO](modulation.md#lfo) | A low-frequency oscillator for modulation: a cheap, block-rate wave to move other parameters. |
| [Random Walk](modulation.md#random-walk) | Smooth random modulation that wanders around `center`, never further than `range` from it. |
| [Step Sequencer](modulation.md#step-sequencer) | A row of step values played one after another, moving on with each `clock` trigger. |

## Utility

Wiring helpers and odds and ends: feedback loops, reroutes, groups, channel tools, notes on the canvas, the engine's vital signs, and plugins installed on the computer. All on one page: [Utility](utility.md).

| Node | What it does |
| --- | --- |
| [Comment](utility.md#comment) | A sticky note on the canvas, for explaining a patch to others or to yourself later. |
| [Feedback](utility.md#feedback) | Sends a signal back to an earlier point in the patch. It is the only way to make a loop: a wire path that leads back to where it started. |
| [Group](utility.md#group) | A piece of patch packed into one node, with its own sockets. Double-click it (or select it and press `Ctrl+Enter`) to go inside and edit it; `Ctrl+Enter` again comes back out. |
| [Info](utility.md#info) | The engine's vital signs as signals: `sample_rate` (Hz), `block_size` (the largest block, in frames), `cpu_load` (how much of each block's time the patch used last block, 0 to 1 and beyond), `xruns` (dropouts so far, from overruns and the audio device), and `latency` (the patch's output latency in samples). *Live source.* |
| [Latency](utility.md#latency) | Delays audio by a fixed number of samples and tells the engine so, which makes it a handy way to see latency compensation at work. |
| [Merge Channels](utility.md#merge-channels) | Combines mono signals into one multichannel signal. |
| [Mid/Side](utility.md#mid-side) | Converts stereo to mid (what both sides share) and side (how they differ), or back, so the center and the edges of a mix can be processed separately. |
| [Plugin](utility.md#plugin) | Runs a CLAP or VST3 plugin installed on this computer as a node: a synth played from MIDI, or an effect on audio. |
| [Reroute](utility.md#reroute) | A dot on a wire, for tidy wiring. Whatever goes in comes straight out, of any type. |
| [Split Channels](utility.md#split-channels) | Splits a multichannel signal into one mono output per channel. |
